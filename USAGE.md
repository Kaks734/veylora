# Veylora — responsible use
Created by Denis Kiriaku.

These are operational guidelines, not additional restrictions on the MIT License.

1. Obtain permission before scanning or changing access on someone else’s network.
2. Identify the correct device using its current MAC and Wi-Fi SSID. A label or DNS name can be inaccurate.
3. Protect the administrator’s Wi-Fi MAC and maintain another route to the router if possible.
4. Review existing rules before enabling filtering. Allowlist mode can lock out unlisted devices.
5. Test blocking on a spare device. Disable its alternative internet connections and verify unblock restores access.
6. Keep credentials, session tokens, private device lists and router screenshots out of public repositories.
7. A blacklist rule reports saved router configuration, not independently proven connectivity loss.
8. The software is provided as is; read LICENSE before redistribution. Retain its notices.
