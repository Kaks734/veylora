# Contributing

Thanks for helping improve Veylora. Start with a reproducible issue, then propose a small change. Run `python -m unittest discover -s tests -v` before submitting a pull request. For interface edits also run `node --check static/app.js` when Node is available and test desktop/mobile layouts in a browser.

Never include passwords, tokens, cookies, real customer device lists or router exports. Use synthetic fixture data. Document supported firmware precisely and test router writes only with permission. Do not add deauthentication, impersonation or fabricated device-location claims. These are project contribution guidelines, not extra terms on the MIT License.
